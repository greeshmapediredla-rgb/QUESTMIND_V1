# SKILLVERSE v2 (Learn it, then run it)
Plain HTML + CSS + JavaScript. No dependencies, no build step, no external assets.
Run locally: `python3 -m http.server 8080` in this folder, then open http://localhost:8080
(or just double-click index.html). Progress is saved in localStorage key `sv2`.
Embed in another site: copy this folder, link to index.html, or use <iframe src="skillverse2/index.html" style="width:100%;height:100vh;border:0">.
